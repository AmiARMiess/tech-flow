# 🚀 TechFlow Landing Page

A modern, responsive, and feature-rich landing page built with pure HTML, CSS, and JavaScript. Perfect for SaaS products, tech startups, or any business looking to make a strong first impression online.

<img width="1349" height="4535" alt="image" src="https://github.com/user-attachments/assets/1f1ef812-9d9e-4b79-b1b8-fa1a60d620bf" />

## ✨ Features

- **Fully Responsive** - Looks great on all devices (mobile, tablet, desktop)
- **Modern Design** - Clean UI with gradient colors, smooth animations, and floating elements
- **Interactive Elements** - Smooth scrolling, scroll animations, parallax effects, and counter animations
- **Mobile-First** - Hamburger menu for mobile navigation
- **Optimized Performance** - Pure vanilla JavaScript, no heavy frameworks required
- **Accessibility** - Semantic HTML structure and ARIA labels
- **Easy to Customize** - Well-organized code with CSS variables for quick theming

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/AmiARMiess/tech-flow.git
   cd tech-flow
   open index.html        # double-click works — no server needed
   ```

## 🎨 Customization

Easily customize the color scheme by modifying CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #0ea5e9;
    --accent-color: #8b5cf6;
    /* ... more variables */
}
```
